**Two halves. One solution.**

Split is a 2D pixel art puzzle platformer where you split into two independently controllable clones to overcome obstacles, solve puzzles and reunite to escape.

## Features

- Splitting and reuniting mechanics
- Two controllable clones
- Four increasingly challenging levels
- Color-coded barriers and pressure plates
- Timed switches and doors
- Interactive tutorial
- Hand-drawn pixel art graphics
- Main menu and ending screen

## Controls

| Key | Action |
| --- | --- |
| A / D | Move left / right |
| SPACE | Jump |
| F | Split / Reunite |
| TAB | Switch between clones |
| R | Restart level |

## How to Play

1. Split yourself into blue and orange clones.
2. Switch between them to navigate obstacles.
3. Activate pressure plates and timed switches.
4. Overcome the puzzles.
5. Reunite and reach the exit.
